# Wellcool App

Flutter project for the Wellcool shopping app.

## GitHub upload
Upload the **contents of this folder** to the root of your GitHub repository so that
`pubspec.yaml`, `lib/`, `assets/`, `android/`, and `ios/` are directly in the repository root.

## Build APK
After pushing to `main`, open GitHub -> Actions -> Build Wellcool APK.
The workflow builds the release APK and stores it as an artifact.
